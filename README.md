# A Question For You 💌

A static page (HTML, CSS, JS). No API keys, no server, no environment variables.

After she answers she gets:
- a **WhatsApp button** that opens a chat with you with her answer pre-filled
- a **downloadable receipt image** (PNG) she can save or share

## Setup
1. Open `script.js` and set `MY_WHATSAPP` near the top, e.g. `"233501234567"` (country code + number, digits only).
2. Deploy the folder to Vercel (drag-and-drop in the dashboard, or push to GitHub and import).
3. Share the link, optionally with her name: `https://your-site.vercel.app/?to=Ama`
